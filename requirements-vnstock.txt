#   pip install -r requirements.txt

# Why a separate file: both packages left PyPI in September 2026. Adding the
# vendor index as an EXTRA index would let pip take a same-named package squatted
# onto PyPI, in a job that holds the production DATABASE_URL. --index-url (not
# --extra-index-url) means pip never looks at PyPI for these two, and the hashes
# reject any file other than the exact wheel that was verified. --no-deps keeps
# every transitive dependency on PyPI via requirements.txt.
#
# 4.0.4 -> 4.0.9 (4.0.4 is not on the vendor index; the oldest there is 4.0.8):

# fetch_foreign_snapshot.py ran clean. Hashes were recomputed from the
# downloaded wheels and match the index. License: Custom (Personal Use).
#

# verify it with `pip hash`, and redo the diff described in requirements.txt.
