## §0 Audit, and the inference failure from the previous phase

### What was wrong, and it was not what I said it was

The previous phase's negative controls flagged `rs20` (8.0%) and
`medTradedValue` (20.0%) as producing corrected-significant results on permuted
labels against a nominal 1%. I attributed this to **heavy tails breaking a
percentile bootstrap**. That explanation is **wrong**, and the correction is
recorded here rather than buried.

Diagnosis, run before this preregistration was written:

| feature | skew | excess kurtosis | obs-level permutation FPR | **cluster-level permutation FPR** |
|---|---|---|---|---|
| `rs20` | 1.27 | 3.6 | 6.7% | **1.3%** |
| `medTradedValue` | 5.18 | 39.5 | 11.0% | **0.0%** |
| `pullbackVolumeContraction` | 4.95 | 48.0 | 3.3% | **1.0%** |
| `distanceToStopAtr` | 0.41 | 0.1 | 3.0% | **0.3%** |

Tail weight does not order the failures — `pullbackVolumeContraction` has the
highest kurtosis of all and was among the *cleanest*. What fixes every case is
computing the statistic at **cluster level** (month means) rather than at
observation level. The real cause is that setups cluster in time: both features
and outcomes are correlated within a month, so observation-level inference
treats ~596 correlated rows as ~596 independent ones.

Replacing the percentile bootstrap with a permutation test does **not** fix it
(9.2% for `rs20`) — the estimator was never the problem.

### Inference permitted in this phase

**Allowed:** cluster-level permutation tests, where the unit is a calendar month,
the statistic is computed on month-level aggregates, and the null is generated by
permuting era labels across months. Empirically calibrated at 0.0–1.3% against a
nominal 1%, which is within Monte Carlo uncertainty at 300 replications.

**Prohibited:** observation-level bootstrap or permutation intervals of any kind
on this dataset, including for descriptive claims. Where an observation-level
number is shown it is labelled descriptive and carries no interval.

**Required:** §13 recalibration of the exact estimator used for each primary
hypothesis, reported before the results are interpreted.

### Reuse

`computeForwardReturnLabels` semantics, `EXCURSION_HORIZON_SESSIONS` (20), ATR
via `computeAtr`, structural stop from Gate 2, the frozen dedup rule, the frozen
regime classification from `5699c69`, the point-in-time guard, and the setups
artifact. New in this phase: per-session MFE/MAE trajectories and cause-specific
first-passage sessions, which the runner now emits; and cluster-level inference
utilities.

## §2 Sample — frozen

Unit: **one unique setup opportunity**, using the dedup rule already frozen in
the previous phase (same symbol, breakout level within 0.5%, within 20 sessions,
earliest kept).

Eras: **2015–2021** vs **2022–2026**, boundary at 2022-01-01, chosen in an
earlier phase and not revisited here.

Both analyses are primary and both are reported:

- **A.** all valid setups
- **B.** the **common-symbol cohort** — symbols producing setups in both eras

If A and B disagree in direction, that disagreement is the headline.

## §3 Replication gate

Before any decomposition is examined, one thing is tested: does
**P(continuation) differ by era** under cluster-level inference?

If the replication fails, the phase stops at `PRIOR DECAY NOT REPLICATED` and no
decomposition is interpreted. If the recalibration in §13 shows the estimator is
still miscalibrated, the phase stops at `INFERENCE PIPELINE NOT CALIBRATED`.

## §14 Primary hypotheses — exactly four

| id | hypothesis | primary statistic |
|---|---|---|
| **H1** | P(continuation) is lower after 2022 | month-level continuation rate, era difference |
| **H2** | the cumulative continuation incidence curve is worse after 2022 | difference in cumulative incidence at T+20, month-clustered |
| **H3** | conditional MFE/ATR given continuation is lower after 2022 | month-level median of continuation MFE/ATR, era difference |
| **H4** | failure arrives earlier after 2022 | month-level median first-failure session, era difference |

**Correction:** Bonferroni over 4 → α = 0.0125. A hypothesis is supported only if
the cluster-level permutation p is below that.

Everything else — per-checkpoint incidence, hazards, quantiles, regime and
volatility strata, giveback, synchronisation, case studies — is **secondary**,
reported with effect sizes and no significance claim. Secondary results may not
be promoted to primary after the fact.

## §4–§5 Lifecycle — frozen definitions

For each setup, from T+1 to T+20, using only information available at each k:

- first session reaching **+2 ATR** (continuation event)
- first session reaching **−1 ATR** (failure event)
- first session touching the setup's **own structural stop** (reported alongside,
  since the previous phase's review showed the fixed −1 ATR is stricter than the
  strategy's own invalidation)

Cumulative incidence of each cause is reported at k = 1, 2, 3, 5, 7, 10, 15, 20.
The **primary object is the curve**; checkpoint values are descriptive.

Cause-specific hazards are reported as smoothed 3-session moving averages,
declared here so that a single-session spike cannot be presented as a mechanism.

## §6–§9 Decomposition — frozen

Reported separately and never combined into a single expectancy number:

- **A. probability** — P(continuation)
- **B. reward given continuation** — MFE %, MFE/ATR, forward 5/10/20,
  time-to-MFE
- **C. adverse behaviour in failures** — MAE %, MAE/ATR, time-to-failure,
  MFE-before-failure
- **D. profit retention** — of setups reaching +1, +1.5, +2 ATR, what fraction
  still hold the gain at T+5/T+10/T+20, what fraction round-trip to entry, what
  fraction end as failures, and the time from peak to giveback

Heavy-tail policy: **median and trimmed statistics lead**; arithmetic means are
shown only alongside the top-1/5/10 contribution and per-symbol concentration.
**R-multiple is excluded entirely.**

## §10–§12 Secondary structure

- **Synchronisation:** failures per date, intra-date clustering, share of
  failures falling on the top failure-cluster dates, index return around failures.
- **Regime stratification:** using the frozen `5699c69` classification, unchanged.
- **Volatility scale:** if percentage excursions shrink but ATR-normalised ones do
  not, the change is a scale effect rather than continuation decay. Both are
  reported.

---

## §13 Negative controls — run before interpreting anything

1. permuted era labels at month level, ≥300 replications, per primary statistic;
2. outcome shuffled preserving date clustering;
3. synthetic heavy-tailed null;
4. common-symbol-cohort null;
5. empirical FPR reported for **each** primary estimator.

If any primary estimator's empirical FPR is not compatible with 1% under Monte
Carlo uncertainty, that hypothesis carries no significance claim.

## §18 Verdict criteria — frozen

Exactly one primary verdict:

| verdict | requires |
|---|---|
| `CONTINUATION DECAY REPLICATED — HIT RATE` | H1 supported, H3 not |
| `CONTINUATION DECAY REPLICATED — PAYOFF COMPRESSION` | H3 supported, H1 not |
| `CONTINUATION DECAY REPLICATED — BOTH` | H1 and H3 both supported |
| `FAILURE BECAME EARLIER / MORE SYNCHRONIZED` | H4 dominant, H1/H3 weak |
| `PRIOR DECAY NOT REPLICATED` | H1 fails under calibrated inference |
| `INFERENCE PIPELINE NOT CALIBRATED` | §13 fails |
| `UNDERPOWERED` | direction consistent but month-level information too thin |

## Stated limits

- **122 months is the real sample size** for anything inferential, not 596 setups.
  Cluster-level inference makes this explicit rather than hiding it.
- Survivorship: 1,182 of 1,537 symbols have no stored bars.
- Ninth phase on one dataset; preregistration constrains this phase only.
- The previous phase's decay finding used observation-level inference now known
  to be miscalibrated. It is treated here as **unreplicated** until §3 says
  otherwise.
