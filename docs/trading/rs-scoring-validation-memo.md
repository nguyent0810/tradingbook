## Evaluation questions

| Question | Metric | Horizon | Success criterion |
| -------- | ------ | ------- | ----------------- |
| Positive RS + negative RS50 underperform? | Median forward return | 10D | RS50+ subgroup beats RS50− by ≥2pp |
| Watch vs Blocked setup states | Median forward return | 10D | Watch median > Blocked (trend) |
| Near Setup qualification rate | P(qualify within N sessions) | 5–10 | Top readiness quartile > baseline |
| NO_TRADE drawdown protection | Max adverse excursion | 10D | Lower tail risk on no_trade days |
| Scoring v1 vs RS20-only sort | Top-decile forward return | 20D | Composite rank improves return without higher DD |

## How to run

```bash
# Enable snapshots (optional on dashboard load)
RS_WATCHLIST_SNAPSHOT_ENABLED=true

# Manual snapshot
npx tsx scripts/save-rs-watchlist-snapshot.ts --limit=30

# Backtest report
npx tsx scripts/rs-watchlist-backtest.ts --json
```

## Sign-off gate

Do not tune RS Strength / Setup Readiness weights until **n≥30** rows per major bucket (Watch breakout, Blocked zone, Blocked MA50).
